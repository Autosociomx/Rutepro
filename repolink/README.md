# RepoLink AI
El puente universal REST API entre cualquier IA y cualquier repositorio Git.

## Objetivo
Permitir que agentes de IA (Gemini, Claude, etc.) realicen operaciones de Git (read, commit, push, branch) mediante simples llamadas a una API REST, eliminando la necesidad de que el humano copie y pegue código.

## Status: MVP
- [x] Estructura base Express
- [x] Schemas para Gemini Function Calling
- [ ] Integración con GitHub API
- [ ] Exposición vía ngrok para AI Studio

## Producto de RoutePro Elite
RepoLink AI nació como una necesidad interna de RoutePro para que la IA pudiera "tocar" el repositorio de forma segura.
